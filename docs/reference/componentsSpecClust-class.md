# Components based on MS/MS similarity.

This class is derived from
[`componentsClust`](https://rickhelmus.github.io/patRoon/reference/componentsClust-class.md)
and is used to store components from feature groups that were clustered
based on their MS/MS similarities.

## Details

Objects from this class are generated by
[`generateComponentsSpecClust`](https://rickhelmus.github.io/patRoon/reference/generateComponentsSpecClust.md)

## Note

When the object is altered (*e.g.* by filtering or subsetting it),
methods that need the original clustered data such as plotting methods
do not work anymore and stop with an error.
