# Compounds list class for MetFrag results.

This class is derived from
[`compounds`](https://rickhelmus.github.io/patRoon/reference/compounds-class.md)
and contains additional specific MetFrag data.

## Usage

``` r
settings(compoundsMF)

# S4 method for class 'compoundsMF'
settings(compoundsMF)
```

## Arguments

- compoundsMF:

  A `compoundsMF` object.

## Details

Objects from this class are generated by
[`generateCompoundsMetFrag`](https://rickhelmus.github.io/patRoon/reference/generateCompoundsMetFrag.md)

## Methods (by generic)

- `settings(compoundsMF)`: Accessor method for the `settings` slot.

## Slots

- `settings`:

  A list with all general configuration settings passed to MetFrag.
  Feature specific items (*e.g.* spectra and precursor masses) are not
  contained in this list.
