# Compounds class for SIRIUS results.

This class is derived from
[`compounds`](https://rickhelmus.github.io/patRoon/reference/compounds-class.md)
and contains additional specific `SIRIUS` data.

## Details

Objects from this class are generated by
[`generateCompoundsSIRIUS`](https://rickhelmus.github.io/patRoon/reference/generateCompoundsSIRIUS.md)

## Slots

- `fingerprints`:

  A `list` with for each feature group result a `data.table` containing
  fingerprints obtained with `CSI:FingerID`.

## S4 class hierarchy

- [`compounds`](https://rickhelmus.github.io/patRoon/reference/compounds-class.md)

  - **`compoundsSIRIUS`**
