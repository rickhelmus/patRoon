# Default adducts for OpenMS componentization

Returns the default adducts and their probabilities when the OpenMS
algorithm is used for componentization.

## Usage

``` r
defaultOpenMSAdducts(ionization)
```

## Arguments

- ionization:

  The ionization polarity: either `"positive"` or `"negative"`.

## Details

See the `potentialAdducts` argument of
[`generateComponentsOpenMS`](https://rickhelmus.github.io/patRoon/reference/generateComponentsOpenMS.md)
for more details.
