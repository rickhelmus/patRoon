# Get supported MS file formats

Returns the supported file formats of MS files in patRoon.

## Usage

``` r
getMSFileFormats(fileType = NULL)
```

## Arguments

- fileType:

  The type of file for which formats should be returned (see
  [`getMSFileTypes`](https://rickhelmus.github.io/patRoon/reference/getMSFileTypes.md)).
  If `NULL` then all file formats are returned.
