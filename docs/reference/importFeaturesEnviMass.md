# Imports features from enviMass

Imports features from a project generated by the enviMass package.

## Usage

``` r
importFeaturesEnviMass(input, analysisInfo)
```

## Arguments

- input:

  The path of the enviMass project.

- analysisInfo:

  A `data.frame` (or `data.table`) with [Analysis
  information](https://rickhelmus.github.io/patRoon/reference/analysis-information.md).

## Value

An object of a class which is derived from
[`features`](https://rickhelmus.github.io/patRoon/reference/features-class.md).

## Details

This function imports data from enviMass. This function is called when
calling `importFeatures` with `type="envimass"`.

## Note

This functionality has only been tested with older versions of enviMass.

## See also

[`importFeatures`](https://rickhelmus.github.io/patRoon/reference/importFeatures.md)
for more details and other algorithms.
